
# Movie Recommendation System

## 1. Project Overview
The Movie Recommendation System is a Machine Learning project that recommends movies based on the user's selected movie.

It uses movie genres and descriptions to identify similar movies.

## 2. Objectives
- Analyze movie information.
- Clean and preprocess the dataset.
- Extract important movie features.
- Build a recommendation model.
- Recommend similar movies to users.

## 3. Dataset
Dataset Name: The Movies Dataset

Source: Kaggle

Link:
https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset

File Used: movies_metadata.csv

## 4. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## 5. Machine Learning Techniques
- Content-Based Filtering
- TF-IDF Vectorization
- Cosine Similarity
